Short course by deeplearning.ai on building Agent Skills with Anthropic. Skills are constructs of instructions that equip agents with on-demand knowledge and workflows. This course teaches best practices for creating reusable, deployable skills.

## Key Learnings

- Create custom skills for code generation and review, data analysis, and research
- Build complex workflows using Anthropic's pre-built skills (Excel, PowerPoint, skill creation)
- Combine skills with MCP and subagents to create agentic systems with specialized knowledge
- Deploy the same skills across multiple platforms including Claude web, Claude Code, Claude API, and the Claude Agent SDK

## Why It Matters

Skills follow an open standard format, enabling build-once-deploy-anywhere capability across any skills-compatible agent. This enables structured, specialized knowledge and reliable, repeatable workflows for agent systems.
